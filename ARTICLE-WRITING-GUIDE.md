# How to Write and Publish Articles

A short guide for writers. No technical knowledge required.

---

## 1. Write in Google Docs

Create a new Google Doc and write your article as usual. Use headings (Heading 2) for sections, bold for emphasis, and links where needed.

**At the very top of the document**, add these lines (you can copy and edit):

```
Title: Your Article Title Here
Subtitle: A short description that appears under the title
Category: Research
Date: 2025-03-15
```

**Categories you can use:** Benchmark, Guides, Usecases, Research, Comparisons, Updates

**Date format:** YYYY-MM-DD (e.g. 2025-03-15)

Leave a blank line after the last line, then write your article.

---

## 2. Add a hero image (optional)

If you want a cover image, add it as the first image in the document. It will be used as the article’s hero image.

---

## 3. Add sources (optional)

At the end of your article, add a section:

```
## Sources

- "Source Title" by Author Name 2024
- "Another Source" by Author Name 2023
```

You can add links: `[Source Title](https://example.com)` by Author Name 2024

---

## 4. Share the document

1. Click **Share** in the top-right
2. Under "General access", choose **Anyone with the link**
3. Set permission to **Viewer**
4. Copy the link

---

## 5. Publish via Telegram

1. Open Telegram and find the Turtle Publisher bot
2. Send the Google Doc link (paste it in the chat)
3. The bot will convert your doc and create a draft
4. You’ll get a preview link and two buttons: **View preview**, **Publish**, **Cancel**

---

## 6. Review and publish

1. Tap **View preview** to open the article in your browser
2. Check the title, subtitle, formatting, and images
3. If everything looks good, go back to Telegram and tap **Publish**
4. If you want to change something, edit the Google Doc and send the link again (the bot will create a new draft)

---

## Quick checklist

- [ ] Title, Subtitle, Category, Date at the top
- [ ] Document shared as "Anyone with the link can view"
- [ ] Link sent to the bot
- [ ] Preview checked
- [ ] Publish tapped
